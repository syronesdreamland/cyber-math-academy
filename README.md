# Cyber·Math Academy — Learning Tracker

Structured self-paced learning tracker with two tracks:

- **Cybersecurity** — 90-day study plan (11 phases), adapted from [90DaysOfCyberSecurity](https://github.com/farhanashrafdev/90DaysOfCyberSecurity).
- **Mathematics** — 7 playlists from [Professor Dave Explains](https://www.youtube.com/@ProfessorDaveExplains).

Every video/material is a checkbox. Progress persists in `localStorage` (works on Android & laptop). Pure static site, no build step.

## Run locally

```
python3 -m http.server 8081
```

Then open http://localhost:8081
